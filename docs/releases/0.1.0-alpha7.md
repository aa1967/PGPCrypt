# PGPCrypt 0.1.0 alpha7

Debian 13 amd64 evaluation package.

- Removes unconditional focus-loss locking. All automatic lock modes are opt-in.
- Settings menu: inactivity slider (1–60 minutes), clipboard wipe slider
  (5 seconds–30 minutes), optional focus/session locking and Light/Dark/Solarized.
- Conversion moved to Settings; notes page removed with existing notes retained.
- On-demand private-key password dialogs replace the notepad password field.
- Subkey inspection and creation under an existing certification primary key,
  with algorithm, purpose, optional password and expiration controls.
- Opt-in Qubes Sign/Decrypt/Lock RPC handlers, bounded transport and same-user
  broker with per-request local approval. Named-client dom0 policy is required;
  no dom0 policy or lock hook is installed automatically. Real Qubes 4.3 transport
  and host events still need evaluation in a guest.

Saves use age payload schema 4 or KDBX settings schema 3. Older vaults open with
new locking/wipe/RPC options off. Older PGPCrypt versions cannot reopen updated
settings; keep a backup before upgrading. KeePassXC compatibility remains.
KDBX writing is experimental upstream. This remains an alpha, not audited crypto
software.
