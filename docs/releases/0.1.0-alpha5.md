# PGPCrypt 0.1.0 alpha5

Debian 13 amd64 evaluation package. Use disposable keys and keep backups.

- Optional KeePass KDBX 4.1 vault creation and automatic detection on opening.
- Save a converted age/KDBX copy with a separately confirmed password; source
  files are left unchanged. Keys, revocations, saved notes and timeout travel.
- Portable protected armored fields for recovery in KeePassXC without PGPCrypt.
- Bounded AES-256/Argon2id KDBX profile; unsupported compression, extensions and
  excessive KDF settings are refused. keepass-rs calls writing experimental.
- Qubes StandaloneVM installation guidance and restricted future qrexec request
  types. RPC services/policies and dom0 lock forwarding are not enabled yet.
- Debian backports supplies the source-build compiler through signed APT;
  installing this compiled package needs no compiler or backports repository.
- GitHub Actions upgraded to commit-pinned Node.js 24 releases.

Install the `.deb` using APT, which resolves its Qt/OpenSSL runtime dependencies.
See the README for download, checksum and installation commands. The internal
Debian version is `0.1.0~alpha5`; the download filename uses `0.1.0.alpha5`.

KDBX is intentionally a limited interoperable profile. Keep compression off
and Argon2id settings within documented limits when editing in KeePassXC. Only
one application should open a vault at a time. KeePass 2 and real Qubes runtime
integration have not been tested here. See the installed design documents for
recovery, unsupported fields and Qubes security boundaries.

Post-push validation: 20 Rust tests passed, Debian KeePassXC 2.7.10 read/edit/save
interoperability passed, and packaged offscreen Qt workflows passed for both
age and KDBX, including lock/restart and permission-error guidance.
