# PGPCrypt 0.1.0 alpha14

Debian 13 amd64 evaluation package.

- Notepad adds Encrypt output and Verify output. Clipboard paste replaces Input.
- Reusable manual Notepad workflows include Sign then encrypt and Decrypt and
  verify; an editor supports ordered, bounded text-only pipelines. Passwords are
  requested normally. Failed steps stop without publishing intermediate results.
- Optional subkey plans create multiple signing, encryption or authentication
  subkeys with individual algorithms/expiries, for new or existing keys. Batches
  save atomically and require a usable certification-capable primary secret.
- Session activity includes sanitized public key identities/fingerprints,
  filenames, setting changes and fixed diagnostic hints. Its header shows vault
  inventory and an optional ASCII welcome. Optional attempt/action counters now
  state their exact window-process lifetime and are checked with failed opens.
- One-click clipboard import reads, clears and imports; New key is labelled
  correctly and unnecessary Offline wording is removed from the interface.

Age writes encrypted payload schema 9; KDBX writes settings schema 8. Older
supported snapshots remain readable; older PGPCrypt releases reject these new
schemas. Preserve backups. Both standard containers, KDFs and key-group mappings
remain unchanged. Workflows/welcome are encrypted and survive conversion.

Profile/key/tag workflow associations are researched, not enabled. Workflows do
not run scripts, save files or act automatically. KDBX writing remains experimental
upstream. Native Qubes/USB/desktop behavior and an independent security audit
remain outside automated component checks. See docs/VALIDATION.md for evidence.
