# PGPCrypt 0.1.0 alpha13

Debian 13 amd64 evaluation package.

- Removes Bubblewrap from the installed launcher, build/install dependencies
  and CI. PGPCrypt starts directly as the desktop user without user namespaces.
- Restores persistent recent-vault history (optional in Vault settings) and
  normal desktop D-Bus access for the existing opt-in lock/suspend handlers.
- Removes sandbox-only path restrictions and outdated settings messages.
- Retains worker memory locking and swap reporting, clipboard cleanup on lock,
  removable-media message controls, saved notes and all alpha12 themes/UI work.
- Keeps sandboxing on the backlog, with Qubes isolation, AppArmor and an optional
  Flatpak distribution documented as possible future approaches. None is enabled.

Package validation exercises the installed launcher's direct startup as an
ordinary user. No vault or crypto format change: age encrypted payload schema 8
and KDBX settings schema 7 remain compatible with alpha12. Older versions may
reject these schemas; keep backups. See docs/SANDBOX.md for runtime boundaries.

Validation will be recorded after the source push. KDBX writing remains
experimental upstream; native desktop/Qubes behavior and an independent security
audit remain outside automated component checks.
