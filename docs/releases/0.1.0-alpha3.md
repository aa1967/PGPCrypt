PGPCrypt for Debian 13 amd64. Download the `.deb` and `SHA256SUMS` attached below.

```sh
cd ~/Downloads
sha256sum --check SHA256SUMS
sudo apt update
sudo apt install ./pgpcrypt_0.1.0.alpha3_amd64.deb
pgpcrypt
```

No Rust/compiler installation is required to run this package.

Changes:
- Configurable Ed25519/Cv25519, RSA 2048/3072/4096 and NIST-curve key creation.
- RSA single-key and primary/subkey layouts, selectable capabilities, optional
  email/public comment, and future expiry dates.
- Required private-key passphrase for generated keys; protection/password
  changes for imported keys and protected private-key export.
- Emergency revocation certificates stored in the vault and available for backup.
- Persistent vault inactivity timeout, 1–60 minutes.
- Installation-only README and automatic `.deb` release attachments.

Vaults still use standard age v1 encryption. The encrypted payload is now schema
2; existing schema-1 vaults open and upgrade on save. Keep a backup before
upgrading: older app versions cannot open schema 2. KDBX support is a documented
proposal, not included in this build. RSA-1024 and DSA/ElGamal generation are
unavailable; existing imports remain subject to Sequoia's security policy.

This is an alpha prerelease, not an independently audited application. Keep
offline backups and evaluate using disposable keys. Source tests and package
checks run in GitHub Actions after pushing; download availability depends on a
successful run. Fresh Debian desktop install/removal and real lock/suspend
integration still need validation.
