# PGPCrypt 0.1.0 alpha9

Debian 13 amd64 evaluation package.

- PGPCrypt workspace with four large navigation buttons: Keys, Notepad,
  Identities and Settings; clearer table rows and theme-aware selection.
- Landing-page recent vaults open the password screen directly. Remembering
  paths is enabled by default; disable it in Settings to clear local history.
  Paths are stored outside vault encryption, never passwords.
- Shared profile tabs with All and +, profile membership management and scoped
  key/recipient/signer/document views. Profiles organize one vault; they do not
  create separate encryption boundaries.
- Verified signer identity, key ID and full fingerprint in the output panel
  and status bar, while keeping verified message text separate from UI labels.
- Encrypted saved Notepad documents with an internal vault browser. External
  import loads text only; external export is a separate explicit action.
  Input Paste and output Copy all controls are included.
- Settings groups special passwords and expiry behind a master control and
  warning. Dummy passwords open an empty read-only view without decrypting or
  modifying the real vault. Inactivity deletion offers days/weeks/30-day months/
  365-day years and applies before decryption on the next overdue unlock attempt.
  All protection options are off initially; see `docs/VAULT_PROTECTION.md`.
- Optional emergency destruction password: a distinct password entered at
  unlock overwrites this vault copy with random bytes at its existing length.
  It requires an adjacent verifier file and explicit opt-in. It cannot hide
  erasure or delete SSD/COW/Qubes snapshot/backup copies. See
  `docs/EMERGENCY_PASSWORD.md` before enabling it.

Saves use age schema 5 or KDBX settings schema 4. Older vaults open with no
profiles/documents; older PGPCrypt versions reject new snapshots. KeePassXC can
read keys and saved documents using ordinary protected fields. Keep backups.
KDBX writing remains experimental upstream, and this application is not
independently audited.

Post-push validation: all 49 Rust checks passed, independent GnuPG/age/KeePassXC
interoperability passed, and packaged Qt workflows passed for age and KDBX,
including profile/document views, recent-history controls, read-only behavior,
Copy/Paste and process replacement on lock. All destruction checks used
disposable fixtures; no system installation or real-Qubes validation was done.
