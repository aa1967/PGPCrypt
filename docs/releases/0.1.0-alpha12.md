# PGPCrypt 0.1.0 alpha12

Debian 13 amd64 evaluation package.

- Bubblewrap launcher isolates networking and temporary XDG state, blocks desktop
  D-Bus/portals, and fails closed if namespaces are unavailable. Recent paths last
  for this launcher lifetime only. Persistent vault folders remain accessible.
- Retained worker vault-password pages use best-effort mlock and wipe-before-
  unmap; Vault settings reports availability and the startup swap check.
- Clipboard cleanup always runs on lock; optional delayed expiry remains off.
- Notepad stays embedded by default. Saved notes has its own navigation page;
  Notepad keeps a small recent list plus load/save and message operations.
- Appearance, locking, clipboard, activity, Qubes and removable-media controls
  are together on Vault settings. New Ruby dark/light, Hacker green and
  Cyberpunk themes supplement the existing palettes.
- Activity includes key creation/import/subkeys, clear-to-Ready, optional auto
  clearing and optional memory-only session counters, with fixed safe messages.
- Verification compares Input signature and Vault key in adjacent rows with
  aligned full fingerprints. Key capability controls align, are selected by
  default, and expiry begins off.
- Message import/export hides and blocks recognized removable locations unless
  enabled. This does not disable OS automounting or affect vault selection.

Age writes encrypted payload schema 8; KDBX writes settings schema 7. Older
schemas remain readable. Existing explicit Notepad preferences are preserved;
missing preferences now default embedded. Older applications reject new
snapshots: back up before upgrading. Standard age/KDBX encryption is unchanged.

Read docs/SANDBOX.md for boundaries: no guarantee of host path invisibility,
universal memory locking, swap encryption or external clipboard deletion.
Desktop D-Bus lock/suspend signals are blocked in the sandbox; use inactivity
locking or the separately configured Qubes hook. KDBX's upstream writer remains
experimental; independent security audit and native Qubes/hardware validation
remain outstanding. Post-push checks passed all 75 Rust tests, independent
age/KeePassXC/GnuPG interoperability, packaged Qt workflows and policy checks.
Live sandbox execution was blocked by this runner’s UID-map restriction;
component tests directly executed the UI/worker. See docs/VALIDATION.md.
