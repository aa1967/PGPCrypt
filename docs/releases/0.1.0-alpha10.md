# PGPCrypt 0.1.0 alpha10

Debian 13 amd64 evaluation package.

- New passwords have no minimum, with local strength indicators and a shared
  128-character limit. Existing longer passwords still unlock.
- Advanced vault protection has master and per-option checkboxes. Turning one
  off disarms and erases its configuration; re-enabling starts fresh. Password
  dialogs remain blank and settings do not expose configured/armed labels.
  Distinctness checks cover the vault password and other salted verifiers,
  including verifiers whose ciphertext binding has gone stale.
- Private-key display and export verify protected secret-packet passwords.
  Exports containing any unprotected packets require the vault password too.
  Original packet encryption is retained.
- Sortable, resizable key tables share identity, full fingerprint, material,
  status, algorithm, creation, expiry and usage information. The Notepad key
  selector is larger. Identity membership remains grouped first when sorting.
- Identity creation starts with editable name, username, email, website and
  private notes. KDBX identity entries use ordinary KeePass fields for recovery
  and compatible edits.
- Saved-document browser adds profiles, timestamps, filtering and properties.
  Updating an opened document and saving a new copy are separate actions.
  New documents default to untitled; duplicate titles within a profile receive
  numbered suffixes. Property changes preserve the document's contents and ID.
- Key creation uses one Encrypt control for both OpenPGP encryption flags;
  authentication remains an optional advanced capability. The sidebar now says
  Vault settings and the duplicate upper Settings menu is removed.

Saves use age schema 6 or KDBX settings schema 5. Older snapshots remain readable;
older PGPCrypt versions reject the new snapshots. Keep backups before upgrading.
KDBX writing remains experimental upstream; the application is not independently
security audited. Optional destruction is best-effort for this copy and cannot
remove SSD/COW/Qubes snapshots or backups, hide configuration or guarantee
plausible deniability. See the design documents for exact boundaries.

Post-push validation passed: all 68 Rust tests; independent GnuPG, age schema
1–6 and KeePassXC interoperability; packaged Qt workflows for both formats,
protection checkbox/dialog setup and reset, private export authentication, and
lock process replacement. No system installation or real Qubes transport test
was performed. Full evidence and limits are in `docs/VALIDATION.md`.
