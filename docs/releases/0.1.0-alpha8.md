# PGPCrypt 0.1.0 alpha8

Debian 13 amd64 evaluation package.

- Text signing produces a readable `PGP SIGNED MESSAGE`; older opaque signed
  messages remain verifiable. Signing leaves the text public.
- Passwordless signing keys proceed directly, including usable unprotected
  signing subkeys under a protected primary. Password dialogs accept blank.
- Notepad Open message and Save output browse ordinary message files. Saving
  plaintext requires confirmation and uses private permissions/atomic replacement.
- Light, Warm light, Dark, Nord, Solarized light and Solarized dark themes.
- Clearer Qubes request setting and shorter workflow messages. RSA-3072 is
  removed from creation menus; existing keys remain supported.
- KDBX entries include portable recovery guidance. Detected outside vault
  changes are refused on save; a post-commit directory-sync failure closes the
  session for reopening. Keep one database editor open at a time and keep backups.
- Imported secret-key password derivation has explicit resource budgets; key
  labels use valid self-bound identities and distinguish mixed key protection.

Vault schemas are unchanged. New theme names require alpha8 in PGPCrypt;
KeePassXC can still open compatible KDBX containers. KDBX writing remains
experimental upstream. See `docs/SECURITY_REVIEW_ALPHA8.md` for the scoped review,
dependency observations, limits and recommended future features.

Post-push validation: 30 Rust tests passed, independent GnuPG/age/KeePassXC
interoperability passed, and packaged Qt workflows passed for both vault
formats, including message save/load. The package requires Debian
OpenSSL `3.5.7-1~deb13u3` or newer, containing current Debian security backports. This remains alpha software without an
independent security audit or real-Qubes transport validation.
