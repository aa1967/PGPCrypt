# PGPCrypt 0.1.0 alpha6

Debian 13 amd64 evaluation package.

- Private-key passwords are optional, with no minimum length. Blank creation
  fields create an unprotected key inside the encrypted vault; matching nonempty
  fields set a password. The key-password dialog can add, change or remove it.
- Explicit private-key export supports these keys and identifies unprotected
  secret packets before displaying them. Existing protected-only worker export
  remains available for callers that require encrypted secret packets.
- Notepad contains all recipient/signing selectors and text-operation buttons.
  The key manager no longer needs to be visited to select text-operation keys.
- Choose and save a default signing key on Notepad. Its fingerprint stays inside
  vault encryption, persists after unlocking and travels through conversion.
  Per-operation signing choices do not overwrite the saved default.

The vault's own password/passphrase still requires 16 characters. Existing age
schemas 1/2 and KDBX settings schema 1 open in alpha6. Saves write age schema 3
or KDBX settings schema 2; older PGPCrypt versions reject those snapshots.
KeePassXC recovery remains available. Keep a backup before upgrading.

KDBX writing remains experimental upstream. Qubes/qrexec support remains the
prepared protocol/design from alpha5; no remote service or dom0 lock forwarding
is installed by this version.

Post-push validation: 22 Rust tests passed, independent age/KeePassXC
interoperability passed, and packaged Qt workflows passed for both age and KDBX
with short/absent key passwords and restored default signing keys.
Previous age schemas 1/2 and KDBX settings schema 1 were also checked for opening
with no saved default; the Notepad layout was reviewed using an offscreen run.
