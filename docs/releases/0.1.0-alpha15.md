# PGPCrypt 0.1.0 alpha15

Debian 13 amd64 evaluation package.

- Automation is a dedicated sidebar page, with up to 32 ordered steps per workflow.
  Each step can inherit Notepad's selection or use its own key combination. Multi-key
  signing supports different private-key passwords; verification can require every
  configured signer.
- Notepad Input and Output are side by side, each with Sign, Verify, Encrypt and
  Decrypt. A workflow selector, source choice and Execute replace the embedded editor.
- Batch mode processes text/armored message files, previews editable destination
  names and supports encrypted filename templates. Every finished job gets a separate
  result window. Queue continuation, stop-after-current-job and cancellation preserve
  independent results. Lock clears session windows and queued work.
- Final outputs save privately without overwriting existing files or following a
  destination symlink. Failed crypto steps publish no intermediate result. Completed
  exports remain when later files fail; readable output is outside vault encryption.

Age writes encrypted payload schema 10; KDBX writes settings schema 9. Earlier
supported vaults remain readable, while older PGPCrypt releases reject the new
schemas. Back up vaults before upgrading. Standard container crypto and canonical
key/identity-group mappings are unchanged. Text-file and queue limits are described
in docs/WORKFLOWS.md. No arbitrary binary processing, scripts or background triggers.

KDBX writing remains experimental upstream. Native Qubes/USB/desktop behavior and
an independent security audit remain outside component checks. See docs/VALIDATION.md.

Post-push validation passed 78 distinct Rust checks (including the corrected new
portability test), independent age/KeePassXC interoperability, removable-media
policy checks and complete packaged desktop workflows for both formats. See
docs/VALIDATION.md for the exact run history and limits. Final documentation-only
repackaging retains the validated executables and launcher.
