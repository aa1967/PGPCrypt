PGPCrypt for Debian 13 amd64. Download the `.deb` and `SHA256SUMS` attached below.

```sh
sudo apt update
sudo apt install -y curl ca-certificates
pgpcrypt_install_dir=$(mktemp -d /tmp/pgpcrypt-install.XXXXXX)
chmod 755 "$pgpcrypt_install_dir"
cd "$pgpcrypt_install_dir"
curl --fail --location --remote-name https://github.com/aa1967/PGPCrypt/releases/download/v0.1.0-alpha4/pgpcrypt_0.1.0.alpha4_amd64.deb
curl --fail --location --remote-name https://github.com/aa1967/PGPCrypt/releases/download/v0.1.0-alpha4/SHA256SUMS
sha256sum --check SHA256SUMS
chmod 644 pgpcrypt_0.1.0.alpha4_amd64.deb
sudo apt install ./pgpcrypt_0.1.0.alpha4_amd64.deb
pgpcrypt
```

Changes:
- Start screen with Create vault, Open vault and Quit.
- File browser for opening vaults and choosing a save location, with Qt settings
  writes disabled and no native portal/recent-file integration.
- Default creation path `~/vault.pgpcrypt.age`. Relative desktop paths and `~/`
  resolve under the current user's home instead of the app's launch directory.
- Password/passphrase labels, mandatory matching confirmation on creation, and
  automatic local zxcvbn strength estimation. No password checks leave the app.
- File-operation errors identify the failed path and include permission guidance.
- The installer stages public packages in a readable temporary directory to
  avoid `_apt` falling back to unsandboxed downloads from private home folders.
- Packaged GUI checks now run as an unprivileged user from a protected package
  directory in CI, using an isolated home for vault creation.

No Rust/compiler installation is needed to run this package. The strength meter
uses Debian's libzxcvbn0 runtime library, installed automatically by APT.
Vault encryption and the encrypted schema are unchanged from alpha3. This
remains alpha software; keep backups and evaluate using disposable keys.
